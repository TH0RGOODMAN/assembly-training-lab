# 设计与验证

## 结构

`domain.mjs`只处理规则和数据，不依赖DOM或Three.js。`app.js`负责三维场景、桌面/WebXR输入及显示。零件与工作台通过几何图元生成。

状态依次为idle → running → completed；重置创建独立的新状态。两个支架完成后才能装转轴，转轴完成后才允许锁紧盖。提交按前置关系、欧氏位置距离、四元数角度差顺序判定，成功后吸附到目标位姿。

阈值为距离≤0.055米、角度≤12度。计分100分，顺序错误扣8分，位置/姿态错误各扣3分；超过180秒后，每完整30秒扣2分，时间扣分上限20分，总分最低0分。完成时间固定，不随等待延长。

## v0.2.0 展示与反馈

结构展示使用独立的预览模型，提供爆炸展开、三阶段装配动画与阶段步进。它不修改训练装配状态，也不把观察动画计入成绩。训练模式的空间连线、投影标记、同轴辅助与容差条根据所选零件的当前位姿更新；考核模式隐藏这些辅助。

零件通过几何图元生成，增加轴肩、锁紧盖等可见结构细节，并用金属材质、阴影和标注改善辨识。视角支持全景、正视、侧视、俯视和所选零件聚焦；提示音通过浏览器 Web Audio 合成，可关闭。

桌面性能面板从当前渲染循环与 Three.js 渲染统计中读取帧率、帧耗时、绘制调用和三角面数量。这是当前页面的观测数据；软件 WebGL、后台负载和不同GPU会改变结果，不能据此宣称头显性能或硬件基准结果。

新增展示、提示音、性能面板、小屏布局与训练/考核流程须针对公开发布候选复核；旧版本浏览器记录不自动作为新版验收结论。
