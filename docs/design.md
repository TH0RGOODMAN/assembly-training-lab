# 设计与验证

## 结构

`domain.mjs`只处理规则和数据，不依赖DOM或Three.js。`app.js`负责三维场景、桌面/WebXR输入及显示。零件与工作台通过几何图元生成。

状态依次为idle → running → completed；重置创建独立的新状态。两个支架完成后才能装转轴，转轴完成后才允许锁紧盖。提交按前置关系、欧氏位置距离、四元数角度差顺序判定，成功后吸附到目标位姿。

阈值为距离≤0.055米、角度≤12度。计分100分，顺序错误扣8分，位置/姿态错误各扣3分；超过180秒后，每完整30秒扣2分，时间扣分上限20分，总分最低0分。完成时间固定，不随等待延长。

- 桌面与390像素小屏视觉及布局检查；实际设备兼容性仍以设备测试为准。
