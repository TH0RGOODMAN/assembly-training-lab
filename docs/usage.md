# 运行、操作与部署

## 打开

Node.js 22+：运行 `node scripts/serve.mjs`，访问终端中的本机地址。网页和Three.js均已附带，启动后不依赖外部CDN。若端口占用，在PowerShell执行 `$env:PORT=8770` 后重试；在其他shell按其环境变量语法设置。

静态网站发布后，直接访问网址即可，不需要Node.js。不要把 `file://` 当成受支持的运行方式。

## 一轮装配

| 动作 | 操作 |
| --- | --- |
| 选择零件 | 点击零件或右侧卡片 |
| 水平定位 | 鼠标左键拖动；W/A/S/D或方向按钮微调 |
| 高度 | R/F或高度按钮 |
| 旋转 | Q/E或旋转按钮；下拉选择X/Y/Z轴 |
| 快速平移 | 按住Shift，步长由10毫米变为50毫米 |
| 提交 | Enter或“确认装配” |
| 观察 | 右键环视、滚轮缩放，或全景/正视/俯视按钮 |

先安装两个支架，再装转轴，最后装两侧锁紧盖。同一阶段可交换先后。判定按工序、位置、姿态依次检查，每次失败只计一个主要错误。

训练模式显示目标与偏差；考核模式隐藏它们，并在开始后禁用成品示意。重新开始会清除本轮，回到可选择模式的准备状态，历史完成记录保留。

## 记录

JSON导出包含模式、完成状态、时间、已完成零件、尝试与错误。`scoreIsFinal` 仅在五件全部装好后为true。下载发生在浏览器；需要长期保存时自行选择合适的位置。

最近五次完成成绩存于当前浏览器的localStorage，使用“清除本机历史”可删除。更换浏览器不会自动同步。应用没有登录或服务器成绩库。

## 头显

WebXR需要兼容浏览器、设备和安全上下文。电脑localhost只代表电脑自身，独立头显不能把它作为电脑地址。跨设备通常需受信任的HTTPS站点。真实设备目前未验证，不建议为这个原型关闭浏览器保护。

## 发布

运行 `node scripts/build.mjs` 后将 `dist/` 部署到静态托管平台。GitHub Pages使用随仓库提供的Deploy demo工作流；仓库Settings → Pages需选择GitHub Actions作为来源。Cloudflare Pages可用构建命令 `node scripts/build.mjs`、输出目录 `dist`。

站点使用相对资源路径，可部署在项目子路径。根README和测试仍保留在源码仓库，网页只包含PUBLIC_FILES列出的文件。发布后检查首页、模块MIME、项目说明、许可和浏览器控制台。

## 常见问题

白屏时先查看下方错误提示，确认通过HTTP服务打开并使用支持WebGL的现代浏览器。没有可用头显时，“进入VR”不可用是预期行为，桌面训练仍可完成。

键盘操作前关闭对话框，并选择零件。已经装好的零件固定在目标位置；在成品示意中不能改变训练状态。手机可以浏览与尝试触控，完整操作优先用电脑。
