# 开发来源与贡献说明

本项目起源于虚拟现实应用课程的装配教学系统需求，随后整理为独立、可运行的公开示例。

## 已确认的范围

- 维护者提出应用与公开整理需求，选择现有装配原型作为第一件开源作品，并授权发布准备。
- 软件开发、文档整理、测试执行与本次发布整理使用了AI辅助。
- 公开仓库包含程序化几何场景、自有规则实现和第三方Three.js库；企业图纸、实习材料、课程身份页及私人工作记录未纳入发布目录。
- 本次发布整理增加运行/构建入口、持续集成、许可与第三方说明、首次使用提示、本机历史清除及小屏展示改进。

## 证据如何表达

自动测试通过只代表所列场景通过。合成控制器位姿不能代表真实设备使用，自动检查所得97分不能代表维护者学习效果。

本仓库不声称维护者独立完成全部源码，亦不声称已经完成真人教学实验、导师验收或真实头显测试。后续个人修改、真实体验与设备测试应以具体变更和记录增量补充。

## 第三方与许可

Three.js r169保留其MIT版权及许可；自有实现和文档以根目录MIT许可发布。署名使用项目维护者标识“hea1.org contributors”，不公开不必要的个人身份信息。
