# Changelog

## 0.2.0 — 2026-11-21

- Added an exploded-view slider, staged assembly playback, phase stepping and assembled-view reset without changing training results.
- Fixed phase stepping, paused playback and completed playback being overwritten by later render frames; added regression checks.
- Preserved small-screen explode-percentage visibility and public keyboard labels.
- Added geometric detail, metallic materials, shadows and part annotations.
- Added spatial alignment guides and live tolerance meters in training mode; assessment keeps these aids hidden.
- Added side view, selected-part focus, optional synthesized sound feedback and desktop render statistics.
- Kept the existing assembly rules, JSON result format, local history, static deployment and experimental WebXR entry.
- Retained public usage, licensing and validation limits; desktop render statistics do not establish headset performance or learning outcomes.

## 0.1.0 — 2026-11-09

- Extracted the existing five-part assembly prototype into a standalone project.
- Added Node.js local serving, explicit static build files and automated checks.
- Added project documentation, MIT licensing and preserved Three.js notices.
- Added visible first-use guidance, labeled adjustment controls and local-history clearing.
- Adjusted small-screen layout and camera framing.
- Retained the existing assembly rules and experimental WebXR input; no physical headset validation is claimed.
